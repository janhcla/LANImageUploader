# Product Guidelines - LANImageUploader (ImageDrop)

## Brand Voice & Tone
- **Professional and Trustworthy:** The brand speaks with authority on security and reliability. Communication is precise, calming, and focused on the integrity of the user's data and workflow.

## Design Principles
- **Clarity and Focus:** The UI must prioritize the user's current task (capture, manage, or upload). Secondary features should be tucked away to ensure that primary workflows are unobstructed and efficient.

## Error Handling & Communication
- **Proactive Recovery:** Errors are treated as hurdles to be cleared, not just failures to be reported. Whenever possible, provide clear, actionable steps for the user to resolve issues, such as checking network connectivity or server credentials.
