# App Store copy draft

This draft is for the selected product name `LensBridge` and should be reviewed
before uploading to App Store Connect.

## English (en-US)

Selected subtitle:

`Private Photo & Scan Transfer`

Suggested keywords (under 100 characters):

`document scanner,PDF,clinic,medical photo,SMB,local server,office capture`

Suggested promotional text:

`Capture clinical photos and scan paper documents into organized PDFs—then send them to your own local server.`

Suggested What's New for version 1.58:

`Document scanning and multi-page PDF workflows, clearer local-only guidance, improved Gallery memory handling, and a built-in SMB connection test.`

Suggested description:

`Capture photos, scan paper documents, create PDFs, and send files to a local SMB server from one focused iPhone workflow.

Designed for clinics, practices, offices, and other teams that need a fast way to move camera images and scanned pages into an existing Windows-based file workflow. Use photo capture for clinical images, document scanning for multi-page paper records, and Gallery tools to rename, reorder, crop, rotate, archive, and create PDFs.

Your files stay on the device until you choose to upload them. Uploads go to the SMB share and target folder you configure on your local network. The SMB password is stored in the iOS Keychain. No cloud storage, analytics, or advertising tracking is included.

Before setup, confirm that your journal or document system can watch a Windows folder and import the file types and filename format you provide. This app transfers files; it does not perform patient lookup, write directly to an EHR, identify patients, diagnose conditions, provide clinical decision support, or guarantee that another system will ingest a file.

Requirements: an iPhone with camera permission for capture and scanning; an SMB server reachable on the same local network; valid server credentials and write access; and a separate journal or document system with a supported import/watch-folder workflow.`

## App Review notes draft

The app is a local-first camera, document scanner, PDF generator, and SMB file
transfer tool. Reviewers can launch it without a server to test photo capture,
document scanning, Gallery, archiving, and PDF generation. SMB upload requires a
reachable test SMB share and credentials supplied by the developer. No patient
data is required or included. The app does not provide an EHR, patient lookup,
diagnosis, cloud backup, or direct journal integration.
